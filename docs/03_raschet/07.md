# Отчеты по расчетам

1. Для анализа сделанных сотрудникам предприятия начислений в конфигурации необходимо предусмотреть отчет следующего вида:

| Подразделение | Сотрудник | Вид расчета | Период 1 | Период 2 | ... |
|---------------|-----------|-------------|----------|----------|-----|
|               |           |             |          |          |     |
| **Итого:**    |           |             |          |          |     |

Отчет может быть построен за любой расчетный период.

2. С помощью диаграммы Ганта показать фактический период действия записей с разбивкой по сотрудникам, и для каждого сотрудника – по видам расчета. Отчет может быть построен за любой расчетный период.
