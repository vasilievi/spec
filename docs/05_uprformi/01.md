# Управляемые формы

## Форма подбора с остатками и ценами 
* Реализация специальной формы подбора (например, для документа «Расходная накладная»).
* Для каждой позиции номенклатуры динамически выводятся её текущий остаток на складе и цена в соответствии с выбранным типом цен (оптовая, розничная). Склад и тип цен берутся из шапки документа.
* При выборе номенклатуры в документ должны автоматически переноситься и товар, и его актуальная цена.

## Подбор методом Drag-and-Drop
* Организация двух таблиц в форме подбора (список всех товаров и таблица отобранных позиций).
* Необходимо реализовать возможность переноса элементов между ними как стандартным выбором, так и перетаскиванием мыши.

## Информационные сообщения в строках ТЧ 
* При нехватке товара сообщения об ошибках не должны выводиться общим списком.
* Их необходимо жестко привязывать к конкретному полю («Количество») конкретной строки табличной части (к первой строке при наличии дублей).

## Функциональные опции и права
* Доступ для пользователей по основным подсистемам (ОУ, БУ, Расчеты) нужно ограничить с помощью функциональных опций.
* Ограничение видимости элементов формы (например, поля «Ответственный старший менеджер» или подсистем) на основании ролей или должности пользователя.
* Требуется учитывать дату документа — были ли права у пользователя на момент создания документа.

## Гиперссылки для сворачивания разделов
* Реализация скрытия/отображения групп элементов (например, «Личные данные») по нажатию на текстовую гиперссылку с динамическим изменением текста самой ссылки.

## Вывод движений в панели навигации 
* Настройка формы документа и формы списка так, чтобы пользователь мог перейти к просмотру записей этого документа по всем регистрам.
* В форме документа доступ организуется через панель навигации, в форме списка — через командную панель.

## Работа с навигационными ссылками 
* Реализация текстовых полей, содержащих навигационную ссылку на другой объект базы (например, e1cib/data/Документ...).
* Требуется запрограммировать кнопку открытия, которая распознает ссылку и осуществляет переход к объекту.

 
## Списки связанных документов на вкладках 
* Размещение на управляемой форме элемента справочника (например, «Физические лица») отдельной закладки, где отображается динамический список документов, в табличных частях которых фигурирует данный элемент.

## Хранение и отображение фотографий: 
* Реализация интерактивного выбора файла изображения с возможностью выбора варианта хранения: в базе или в виде пути к файлу на диске.
* Картинка должна отображаться на форме сразу после выбора, но записываться в базу только при сохранении самого элемента справочника.

## Взаимодействие с задачами: 
* Автоматическое открытие форм невыполненных задач пользователя по мере их генерации регламентным заданием.
* Вывод на рабочий стол списков актуальных задач текущего пользователя с возможностью перехода к полному списку задач.
